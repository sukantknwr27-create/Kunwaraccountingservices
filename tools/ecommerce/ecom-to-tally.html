How to import into Tally

      

        1. In Tally, first create the Sales, Party and Tax ledgers exactly as named in Step 4 (skip this if "Auto Create Ledger" is checked and your Tally version supports ledger auto-creation on import).

        2. Go to Gateway of Tally → Import Data → Vouchers and select the downloaded XML file.

        3. Review the import summary Tally shows before accepting — always test on a backup company first.
