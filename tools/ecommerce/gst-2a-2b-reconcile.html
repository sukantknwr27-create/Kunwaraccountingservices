What each category means

Matched Entry — GSTIN + invoice number found in both, values match within tolerance.
Amount Mismatched — same GSTIN + invoice number in both, but taxable value or tax amounts differ beyond tolerance.
Invoice Mismatched — the supplier appears in 2A/2B and a similar invoice value exists, but the invoice number doesn't match exactly — check for a typo on either side.
Entry Pending — the supplier has filed their return (other invoices from them appear in 2A/2B) but this specific invoice hasn't shown up yet.
Return Pending — the supplier's GSTIN doesn't appear in 2A/2B at all for this period — their return itself is pending.
