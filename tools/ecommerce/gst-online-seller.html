How this tool works

Set your GSTIN and return period once, then import each marketplace's tax/order report — we auto-detect columns per platform. Every platform's data is grouped by place of supply and GST rate for GSTR-1 Table 7 (B2C Others) and Table 4 (B2B). The downloaded Excel mirrors the official GSTR-1 offline utility layout; the JSON follows the general portal structure for reference — always cross-check figures on the GST portal before filing.
